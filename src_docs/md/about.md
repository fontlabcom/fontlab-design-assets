# About

These assets are published by [Fontlab Ltd.](https://www.fontlab.com/) for
partners, press, and the type community.

## Using the assets

- Represent FontLab products and partnerships with the wordmark, banners, and app icons here.
- Keep the logo intact: no stretching, no recoloring beyond the black and gray tints provided.
- Need a size or format that is missing? Ask before improvising one.

## Contact

For usage questions or a missing asset, open an issue on the
[repository](https://github.com/fontlabcom/fontlab-design-assets/issues).
